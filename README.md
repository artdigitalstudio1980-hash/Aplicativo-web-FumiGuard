# FumiGuard — Fumigación a Domicilio 🛡️

Sitio web moderno para servicios de fumigación a domicilio: servicios, cotización y contacto por WhatsApp.

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Tailwind](https://img.shields.io/badge/Tailwind-06B6D4?style=for-the-badge&logo=tailwindcss&logoColor=white)

## ✨ Features
- Landing de servicios (hogar, negocio, jardines)
- Cotización rápida + botón WhatsApp
- Formulario de contacto
- SEO básico + responsive

## 🚀 Getting Started
```bash
npm install
npm run dev
# http://localhost:3000
```
